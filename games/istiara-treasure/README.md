# كنز الاستعارة المكنية

لعبة عربية من **خمسة أسئلة فقط**، مناسبة لنشاط ختامي عن الاستعارة المكنية. كل إجابة صحيحة تفتح قفلًا. تشمل تصحيحًا وتفسيرًا لكل إجابة ونتيجة نهائية ومراجعة وإعادة لعب.

## التشغيل

نزّل `index.html` وافتحه في أي متصفح حديث. يعمل دون تثبيت أو اتصال بالإنترنت، ولا يحتاج إلى مكتبات أو خدمات خارجية. رابط GitHub يعرض الكود؛ ليس رابط تشغيل مباشرًا.

## المحتوى

الأسئلة أمثلة تدريبية مؤلفة لهذه اللعبة وليست منقولة من عرض دراسي مرفق. يمكن تعديل مصفوفة `questions` داخل الملف، مع الإبقاء على خمسة أسئلة. لا تُجمع بيانات ولا تُرسل طلبات شبكة.

## التحقق

تم اختبار مسارات الإجابات الصحيحة والخاطئة والمختلطة، ومنع احتساب الإجابة أكثر من مرة، والتقدم والمراجعة وإعادة اللعب باستخدام محاكاة DOM. تعذر اختبار العرض البصري في متصفح فعلي لعدم توفر Chromium في بيئة التنفيذ.
